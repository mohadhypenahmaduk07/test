# StockPilot Pro: Advanced Inventory Management System

StockPilot Pro is a portfolio-ready inventory management web app for tracking products, stock health, suppliers, purchase orders, reorder risk, analytics, and CSV exports.

## Live Demo

GitHub Pages target: https://mohadhypenahmaduk07.github.io/test/

If the live demo is still building, open the repository and wait for the latest Pages deployment workflow to finish.

## Features

- Inventory dashboard with total SKUs, inventory value, low-stock alerts, and open orders
- Product add, edit, delete, search, and filter workflows
- Smart stock status engine for healthy, low, critical, and overstock items
- Reorder queue with draft purchase order generation
- Purchase order board by Draft, Submitted, In Transit, and Received
- Supplier cards with risk and inventory value metrics
- Analytics charts for category value and demand forecast risk
- CSV export for reporting
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- GitHub Pages
